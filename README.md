# Mechanics Point Score — Student Management System

A Next.js application for managing mechanics students, tracking scores/progress, generating reports (PDF/Excel), and administering assessments. Uses Drizzle ORM with SQLite/PostgreSQL and Tailwind CSS.

## Technology stack

- **Frontend/Backend:** Next.js 16, React 19, TypeScript.
- **Database:** Drizzle ORM, better-sqlite3 / pg.
- **UI:** Tailwind CSS 4, Recharts, lucide-react.
- **Utilities:** date-fns, nanoid, exceljs, pdf-lib.

## Running locally

Prerequisites: Node.js 20+.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Scripts

- `npm run dev` — development server.
- `npm run build` — production build.
- `npm run start` — production server.
- `npm run lint` — ESLint.
- `npm run typecheck` — TypeScript.
